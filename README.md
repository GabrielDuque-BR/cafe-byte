# cafe-byte

Café quentinho, código fresquinho!

O Café Byte é um site fictício de cafeteria, desenvolvido como projeto prático do curso Web do Zero, com o objetivo de aplicar conhecimentos de desenvolvimento web utilizando HTML, CSS e JavaScript.

O projeto simula uma cafeteria moderna, combinando uma interface responsiva com funcionalidades interativas para melhorar a experiência do usuário.

🌐 Acesse o projeto

"Visitar o Café Byte" (https://gabrielduque-br.github.io/cafe-byte/)

🚀 Funcionalidades

- Página responsiva: layout adaptado para computadores, tablets e celulares.
- Cardápio interativo: apresentação dos produtos com descrições e preços.
- Busca e filtros: pesquisa de produtos por nome e categoria.
- Carrinho de compras: adição e remoção de produtos com cálculo automático do valor total.
- Armazenamento local: utilização do "localStorage" para preservar os itens do pedido.
- Consulta de CEP: preenchimento automático do endereço por meio da API ViaCEP.
- Previsão do clima: consulta da temperatura atual utilizando a API Open-Meteo.
- Modo escuro: alternância entre temas claro e escuro.
- Saudação dinâmica: mensagem personalizada de acordo com o horário do visitante.
- Status de funcionamento: indicação automática de cafeteria aberta ou fechada.
- Menu responsivo: navegação adaptada para dispositivos móveis.

🛠️ Tecnologias utilizadas

HTML5

- Estrutura e organização do conteúdo.
- Formulários e elementos semânticos.

CSS3

- Estilização e identidade visual.
- Flexbox e CSS Grid.
- Media queries e responsividade.
- Animações e efeitos de interação.

JavaScript

- Manipulação do DOM.
- Eventos e funções.
- Arrays e objetos.
- Condicionais e estruturas de repetição.
- Armazenamento com "localStorage".
- Requisições assíncronas com "fetch()".

🔗 APIs utilizadas

ViaCEP: consulta de endereços a partir do CEP informado pelo usuário.

Open-Meteo: consulta de dados meteorológicos para apresentar a temperatura atual.

🎯 Objetivo do projeto

Desenvolver habilidades práticas em programação web, compreendendo a integração entre HTML, CSS e JavaScript na construção de páginas interativas.

O Café Byte representa uma etapa inicial do meu aprendizado em desenvolvimento de software e da construção do meu portfólio de projetos.
